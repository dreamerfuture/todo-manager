# 个人待办事项管理器

一个基于 **Vue 3 + Vite** 的轻量级待办事项管理应用。所有数据保存在浏览器本地（localStorage），无需后端与数据库，开箱即用。

## 功能特性

| 功能 | 说明 |
|---|---|
| 新增任务 | 内容必填校验 + 重复检测；可设置优先级（高/中/低）与截止日期；支持回车快捷添加 |
| 编辑任务 | 行内编辑内容 / 优先级 / 截止日期，回车保存、Esc 取消 |
| 完成管理 | 勾选或取消完成，已完成任务文字划线置灰 |
| 删除 | 单条删除；一键清空已完成（带二次确认） |
| 筛选 | 全部 / 进行中 / 已完成 三个视图切换，并实时显示数量 |
| 统计 | 任务总数、已完成、进行中、完成率统计卡 + 进度条 |
| 逾期提示 | 未完成且超过截止日期的任务，日期标红加粗 |
| 本地持久化 | 任何修改自动写入 localStorage，刷新或关闭页面不丢失 |

## 技术栈

- **Vue 3**（组合式 API + `<script setup>`）
- **Vite** 构建与开发服务器
- **原生 CSS**（Flexbox 布局，无 UI 框架依赖）
- 数据持久化：浏览器 **localStorage**

## 快速开始

环境要求：Node.js ≥ 18（推荐 20 LTS 及以上）。

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 构建生产版本，产物输出到 dist/
npm run build

# 本地预览构建结果
npm run preview
```

Windows 用户也可以直接双击项目根目录下的 `启动开发服务器.bat` 启动开发服务器。

## 两种实现

本项目提供两套功能等价的实现，便于对比不同技术方案的取舍：

| 实现 | 位置 | 技术 | 运行方式 |
|---|---|---|---|
| **原生实现** | `vanilla/` | HTML + CSS + 原生 JavaScript（无框架、无构建） | **双击 `vanilla/index.html`** 即可打开；也可直接把该文件夹部署到静态托管平台 |
| **组件化实现** | 仓库根目录 | Vue 3 + Vite | `npm install` → `npm run dev` |

两者功能一致（新增 / 编辑 / 删除 / 完成 / 筛选 / 统计 / 逾期提示 / 本地持久化），差别在于：

- **原生实现**：自己维护一份数据数组，每次修改后手动调用 `render()` 重新渲染界面，用事件委托处理交互。代码集中在 `app.js`，依赖为零，双击即可运行。
- **组件化实现**：由框架的响应式系统在数据变化时自动更新界面，页面拆分为多个可复用组件，适合功能持续增长的项目，但引入了框架的学习成本与构建步骤。

## 项目结构

```
todo-manager/
├── index.html                 # Vue 版页面入口
├── vite.config.js             # Vite 配置
├── package.json               # 依赖与脚本
├── 启动开发服务器.bat          # Windows 一键启动脚本
├── src/                       # Vue 版源码（组件化实现）
│   ├── main.js                # 应用入口：创建并挂载应用
│   ├── style.css              # 全局样式
│   ├── App.vue                # 根组件：页面骨架
│   ├── store/
│   │   └── todos.js           # 数据层：状态、增删改查、本地持久化
│   └── components/
│       ├── TodoInput.vue      # 新增任务表单
│       ├── TodoStats.vue      # 统计信息与进度条
│       ├── TodoList.vue       # 任务列表与筛选
│       └── TodoItem.vue       # 单条任务（含行内编辑）
└── vanilla/                   # 原生实现（无框架、无构建）
    ├── index.html             # 页面结构
    ├── style.css              # 样式
    └── app.js                 # 全部逻辑：数据 → 渲染 → 事件
```

### 代码组织说明

- **数据层集中管理**：`src/store/todos.js` 用 `reactive` 维护一份全局状态，并提供增删改查方法；任何组件通过 `useTodos()` 拿到的是同一份数据。
- **自动持久化**：数据层用 `watch` 深度监听状态变化，自动写入 localStorage。
- **组件通信**：父组件 `TodoList` 通过 `props` 向 `TodoItem` 传数据，子组件通过 `emit` 上报操作；其余组件直接调用数据层方法。
- **派生数据**：统计信息、筛选结果均由 `computed` 计算得出，数据变化时界面自动更新。

## 数据存储

- localStorage 键名：`todo_manager_data`
- 数据仅保存在当前浏览器中，不会上传到任何服务器
- 清除浏览器数据或使用无痕窗口会导致数据丢失；可在浏览器开发者工具（F12）→ Application → Local Storage 中查看

## 浏览器兼容性

使用标准化 CSS 与 Flexbox 布局，已在 Chrome、Edge、Firefox 主流版本下测试，界面与交互表现一致。

## 常见问题

| 问题 | 解决方法 |
|---|---|
| `npm run dev` 提示端口被占用 | 修改 `vite.config.js`，添加 `server: { port: 5174 }` 后重启 |
| 修改代码后页面没变化 | 确认修改的是 `src/` 下的文件；Vite 会热更新，必要时手动刷新 |
| 刷新后任务不见了 | 可能使用了无痕窗口，或清理过浏览器数据；数据只存在于本机浏览器 |
| `npm install` 失败 | 确认 Node.js 版本，删除 `node_modules` 后重新安装 |

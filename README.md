# 个人待办事项管理器（Web 前端版）

《Web开发实践》课程选题 #26（交互应用类，难度低，约束：交互与表单校验）
技术栈：HTML5 + CSS3 + JavaScript + **Vue 3（Vite）**，数据存于浏览器 localStorage。

## 一、运行方法

```bash
# 1. 安装依赖（第一次运行才需要，会生成 node_modules 目录）
npm install

# 2. 启动开发服务器
npm run dev
# 浏览器访问 http://localhost:5173

# 3.（可选）打包上线
npm run build     # 生成 dist/ 目录
npm run preview   # 本地预览打包结果
```

> 环境要求：Node.js ≥ 18（建议 20 LTS），VS Code 建议安装 Volar 插件（.vue 文件语法高亮）。

## 二、项目结构与代码导读（按学习顺序读）

```
todo-manager/
├── index.html                 # 入口 HTML：只有 <div id="app">
├── vite.config.js             # Vite 配置（启用 Vue 插件）
├── package.json               # 依赖与 npm 脚本
├── src/
│   ├── main.js                # ① 入口：创建应用并挂载
│   ├── style.css              # ② 全局样式
│   ├── App.vue                # ③ 根组件：页面骨架，拼装 3 个组件
│   ├── store/
│   │   └── todos.js           # ④ 数据中心（核心！）：数据 + 增删改查 + 自动保存
│   └── components/
│       ├── TodoInput.vue      # ⑤ 新增任务（v-model 表单 + 校验）
│       ├── TodoStats.vue      # ⑥ 统计卡片（computed 派生数据）
│       ├── TodoList.vue       # ⑦ 列表 + 筛选（父组件：改数据）
│       └── TodoItem.vue       # ⑧ 单条任务（子组件：props 收数据 / emit 报操作）
```

**建议阅读顺序：main.js → App.vue → store/todos.js → TodoInput → TodoStats → TodoItem → TodoList**
（先懂"数据从哪来、改数据的方法在哪"，再看组件怎么用界面操作数据。）

## 三、功能清单

| 功能 | 说明 |
|---|---|
| 新增任务 | 内容必填校验 + 查重校验；可选优先级(高/中/低)与截止日期 |
| 编辑任务 | 行内编辑（内容 / 优先级 / 截止日期），回车保存、Esc 取消 |
| 完成管理 | 勾选/取消完成，完成后文字划线置灰 |
| 删除 | 单个删除、一键清空已完成（带确认） |
| 筛选 | 全部 / 进行中 / 已完成 三个标签 + 实时计数 |
| 统计 | 总数 / 已完成 / 进行中 / 完成率 + 进度条 |
| 逾期提示 | 未完成且超过截止日期时，日期标红加粗 |
| 本地保存 | 任何修改自动写入 localStorage，刷新不丢 |

## 七、常见问题

- `npm run dev` 报端口占用：改 `vite.config.js` 加 `server: { port: 5174 }`
- 界面改了没生效：确认保存的是 `src/` 下文件；Vite 改动即热更新
- 数据"丢了"：可能用了无痕窗口或清理过浏览器数据；可在 DevTools → Application → Local Storage 查看

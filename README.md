# 个人待办事项管理器

一个基于 **原生 HTML / CSS / JavaScript** 的待办事项管理应用。数据保存在浏览器本地（localStorage），无需后端、无需安装依赖、无需构建，**双击页面即可使用**。

## 功能特性

| 功能 | 说明 |
|---|---|
| 新增任务 | 内容必填校验 + 重复检测；可设置优先级（高/中/低）与截止日期 |
| 编辑任务 | 行内编辑内容 / 优先级 / 截止日期，支持保存与取消 |
| 完成管理 | 勾选或取消完成，已完成任务文字划线置灰 |
| 删除 | 单条删除；一键清空已完成（带二次确认） |
| 筛选 | 全部 / 进行中 / 已完成 三个视图切换 |
| 统计 | 任务总数、已完成、进行中、完成率 + 进度条 |
| 逾期提示 | 未完成且超过截止日期的任务，日期标红加粗 |
| 本地持久化 | 任何修改自动写入 localStorage，刷新或关闭页面不丢失 |

## 技术栈

- HTML5 + CSS3（Flexbox / Grid 布局、CSS 变量式配色）
- 原生 JavaScript（ES6+：`map/filter`、模板字符串、事件委托）
- 数据持久化：浏览器 **localStorage**

## 快速开始

**方式一（最简单）**：双击 `vanilla-plus/index.html`，用浏览器打开即可。

**方式二（可选，本地静态服务器）**：

```bash
npx serve vanilla-plus
```

无需 `npm install`，也无需构建步骤。

## 目录结构

```
todo-manager/
├── vanilla-plus/            # 主实现：3 个文件，约 210 行
│   ├── index.html           # 页面结构
│   ├── style.css            # 界面样式（卡片、统计卡片、进度条、优先级配色）
│   └── app.js               # 全部逻辑：数据 / 渲染 / 事件
└── vanilla/                 # 教材版：功能相同，注释更完整，便于阅读学习
    ├── index.html
    ├── style.css
    └── app.js
```

### 代码组织说明（以 `vanilla-plus/app.js` 为例）

- **数据层**：`todos` 数组是唯一数据源，`save()` 负责写入 localStorage，`over()`、`esc()` 等为纯工具函数。
- **渲染层**：`render()` 一次完成列表、统计、进度条、筛选高亮与空状态；数据变化后调用它即可刷新界面。
- **事件层**：列表用**事件委托**在一个父容器上监听（通过 `data-a` 区分操作），筛选按钮单独绑定一次，避免逐个元素绑定。
- **组件形态**：每条任务在"浏览态"与"编辑态"之间切换，由 `editing` 变量记录当前编辑的任务 id。

## 数据存储

| 实现 | localStorage 键名 |
|---|---|
| `vanilla-plus/` | `todo_plus` |
| `vanilla/` | `todo_manager_plain` |

数据仅保存在当前浏览器中，不会上传到任何服务器；清除浏览器数据或使用无痕窗口会导致数据丢失，可在开发者工具（F12）→ Application → Local Storage 中查看。

## 浏览器兼容性

使用标准化 CSS 与 Flexbox/Grid 布局，已在 Chrome、Edge、Firefox 主流版本下测试，界面与交互表现一致。

## 常见问题

| 问题 | 解决方法 |
|---|---|
| 双击页面后界面空白 | 确认 `index.html`、`style.css`、`app.js` 三个文件在同一目录且文件名未改动 |
| 任务刷新后丢失 | 可能使用了无痕窗口或清理过浏览器数据；数据只存在于本机浏览器 |
| 想清空全部任务 | 在浏览器控制台执行 `localStorage.removeItem('todo_plus')` 后刷新 |
| 复制到其它电脑 | 直接拷贝整个文件夹即可，无需安装任何环境 |
